**Project Name:** Cars Dealership — Full Stack Application

**Project Type:** IBM Full Stack Application Development Capstone Project

## Project Description

Cars Dealership is a full-stack web application developed as part of the IBM Full Stack Application Development Capstone Project.

The application allows users to explore car dealerships, filter dealerships by state, view dealership information, read customer reviews, register accounts, log in, and submit their own reviews.

## Technologies Used

- **Backend:** Python, Django
- **Frontend:** React, JavaScript, HTML, CSS
- **Database:** SQLite
- **Authentication:** Django Authentication
- **Version Control:** Git and GitHub
- **CI/CD:** GitHub Actions
- **Deployment:** Render

## Main Features

- User registration and authentication
- User login and logout
- Dealership listing
- Dealership filtering by state
- Dealership details and customer reviews
- Review submission for authenticated users
- Car makes and models listing
- Sentiment analysis of customer reviews
- Django administration panel
